# AirDosa 🚁 - AI-Powered Instant Dosa Delivery

A modern, high-tech, and fully interactive landing page for **AirDosa**, a fictional Indian startup offering AI-driven instant dosa delivery via autonomous drone fleets.

## Features
- **Dynamic Dark/Light Themes**: Smooth transitions between a futuristic neon dark mode and a high-tech light mode.
- **Micro-Animations**: Hover animations on the delivery drone, ambient button pulses, and scroll-triggered section entries.
- **Custom Flight Dispatch Drawer**: Order customizable dosas with a dynamic **Spice Flight Level** slider (from *Mild* to *AI Hyper-Combustion*).
- **Live Telemetry & Radar Simulator**: Watch real-time drone coordinates moving on a scanning radar screen and live-scrolling terminal console output.

## Tech Stack
- **Structure**: HTML5 (Semantic Structure)
- **Styling**: CSS3 (Vanilla Custom HSL Variables, Glassmorphism, Responsive Grid System)
- **Icons**: Lucide Icons (imported via CDN)
- **Tooling**: Vite (Modern dev server for fast local previewing)

## Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/abduljainbee-dev/AirDosa1.git
   cd AirDosa1
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.
